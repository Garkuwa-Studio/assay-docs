The board shows what issuers publish. If something is wrong, anyone, issuers
included, can ask for a correction. Each correction is fixed in the next
census and logged here with its date.

## How to ask

Use the **correction link** on the asset's page on
[the board](https://assay.wtf/board/). It opens a pre-filled issue with the
asset, the field and the snapshot. Say what's wrong and link a source.
